# Домашнє завдання до тем 7 та 8

Розв'язання виконані на Python 3.10+.

## Структура

- `tree.py` — реалізація двійкового дерева пошуку та вузла дерева.
- `task1.py` — пошук найменшого значення в BST.
- `task2.py` — обчислення суми всіх значень у BST.
- `task3.py` — пошук мінімальної вартості з'єднання кабелів за допомогою мін-купи.
- `test_homework.py` — автоматичні тести.

## Запуск прикладів

```bash
python3 task1.py
python3 task2.py
python3 task3.py
```

## Запуск тестів

```bash
python3 -m unittest -v
```

## Складність алгоритмів

- Пошук мінімуму в BST: `O(h)`, де `h` — висота дерева.
- Сума значень у BST: `O(n)` часу та `O(n)` пам'яті у найгіршому випадку.
- З'єднання кабелів: `O(n log n)` часу та `O(n)` пам'яті.

Для кабелів на кожному кроці обираються два найкоротші доступні кабелі. Це оптимальна жадібна стратегія для мінімізації загальної вартості.
